
# DeepShield 🛡️
### AI-Based Preventive Framework for Deepfake Protection

## 📌 Project Overview
DeepShield is an AI-based preventive framework designed to protect facial images against potential deepfake manipulation.

The system uses image processing, adversarial techniques and deep learning to improve the robustness of facial images against manipulation.

## 🎯 Objectives
- Develop a preventive approach to deepfake protection.
- Apply adversarial techniques to facial images.
- Evaluate image quality after protection.
- Build an interactive application for image processing.

## ⚙️ Technologies Used
- Python
- Streamlit
- PyTorch
- OpenCV
- Deep Learning
- FGSM (Fast Gradient Sign Method)

```bash

```

### 2. Install dependencies

```bash

```

### 3. Run the application

